# Caderno de Receitas — Projeto A3 (Grupo 9)

Projeto base configurado em **React + Vite** para desenvolvimento da aplicação de receitas usando a API pública **TheMealDB**.

## Bibliotecas instaladas

- `react` e `react-dom`
- `react-router-dom` (rotas)
- `lucide-react` (ícones)

## Como rodar localmente

```bash
npm install
npm run dev
```

Outros comandos:
- `npm run build` — gera o build de produção em `dist/`
- `npm run lint` — verifica erros com ESLint

## API utilizada

- **TheMealDB:** https://www.themealdb.com/
- **Base URL:** `https://www.themealdb.com/api/json/v1/1`
